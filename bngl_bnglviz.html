Usage and limitations:
  • Non-visual parts of BNGL code such as parameter blocks and actions are omitted in visualization for clarity, but comments for molecules, species, rules, and observables are displayed.
  • No code validation is provided: the BNGL is visualized as is.
  • cBNGL is not supported, but compartmental export from VCell is supported.
