About this Sandbox

This sandbox is intended for quickly creating and visualizing BNGL models. Paste BNGL code into the editor and click Visualize.

Molecule types are required for visualization. Parameters, functions, actions, and other non-visual components are ignored.

This sandbox can help identify some inconsistencies, but it is not intended to be a comprehensive BNGL validator.
